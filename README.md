# Blind Hands

Visual Reliance and Feedback Error in Dexterous Imitation.

Anonymous project website containing the research overview, manuscript, English and Chinese two-minute demos, selected task-outcome examples, and 33 full recording copies.

Open `index.html` through a static web server. All media and research assets are included locally. Video examples illustrate visible outcomes; the recordings are not a count of independent trials and do not identify methods or experimental conditions.

The web page distinguishes the controlled three-seed state-dropout study from the exploratory tactile, consistency-noise, and ACT comparisons. See the manuscript and metric definitions for the evaluation scope.
