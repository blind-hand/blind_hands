Blind Hands — Anonymous review video archive

All 33 supplied recordings and five edited demos are preserved.
Recording count is not a trial count. Model identities and experimental
conditions are unassigned; videos illustrate visible behavior only.

Review downloads preserve the compressed video packets and full resolution.
Browser previews preserve the existing full-length 1x H.264 video stream.
All audio, chapters and identifying container metadata have been removed.
The files are anonymized copies, not byte-identical original downloads.

SHA256SUMS.txt and recordings.csv refer to these review copies.
edit-timeline.json retains source IDs and temporal provenance.

Download each recording from its card, or run:
python download_archive.py --base-url URL_OF_ANONYMOUS_PROJECT_PAGE
Replace the final argument with the actual anonymous project page URL.
No external personal website is used as a fallback.
